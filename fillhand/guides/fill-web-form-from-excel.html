How to fill a web form from an Excel sheet, row by row

You have a spreadsheet with 300 rows and a web form that takes one record at a time. Here is how to have Chrome type them in for you — and know which ones failed.

What you need: Chrome, the free Fillhand extension and your Excel or CSV file. No account, no code. Your data never leaves your computer.

Step by step

  1. Install Fillhand and pin it. Click the toolbar icon to open the side panel.
  2. Open the form in a tab. In the panel, choose Record new and fill the form once by hand, exactly as you normally would — type, pick from dropdowns, tick boxes, click Save.
  3. Click Stop. Each action is now a step you can read and edit.
  4. Go to Data and import your CSV or Excel (.xlsx) file. The first row should hold the column names.
  5. Open the macro, set Data source to your file, and replace each typed value with a placeholder: click the value, then {{row.Email}}, {{row.Company}} … (the panel lists your columns).
  6. Press Run. Fillhand repeats the macro once per row and shows ✓ or ✗ for each one.
  7. If a row fails, the panel shows which step and why. Fix it and press Run failed and remaining rows — rows already done are not entered twice.
  8. Export the results as CSV (with a status column) if you need a record of what was entered.

Tips that save a rerun

  • Record with a real row of data so dropdowns and checkboxes are recorded the way the site expects.
  • Dropdown values can be the text you see (Viet Nam) or the hidden value — both work. Several choices in one cell: Red; Blue.
  • Checkbox columns can be yes/no, x/empty or 1/0. Use the step's Tick from data field.
  • Excel dates such as 05/11/2026 are converted for date fields.
  • Add a Wait for element step after Save (for example the “Saved” message) so the next row only starts when the site is ready.
  • Run 2–3 rows first with Start at row, then the rest.
