Checkboxes, radio buttons and dropdowns from CSV columns

Text fields are easy. The forum threads are full of the rest: ticking boxes from a column, picking the right option, multi-selects. Here is how Fillhand handles each.

What you need: Chrome, the free Fillhand extension and your CSV or Excel file. No account, no code. Your data never leaves your computer.

Step by step

  1. Record the form once, ticking and choosing as usual.
  2. Checkbox step → Tick from data: {{row.Newsletter}}. yes, y, x, 1, true, có tick; no, n, 0, false or empty untick.
  3. A group of checkboxes from one cell: put the options in the cell separated by ; — News; Sales. Fillhand ticks those and unticks the rest. Values or label text both work.
  4. Radio buttons: Tick from data with the option's label or value — Medium.
  5. Dropdowns: the Choose step's value {{row.Country}} matches the option value, then the visible text, ignoring case.
  6. Multi-select lists: Red; Blue selects both.
  7. Custom dropdowns (the ones that are really divs): record clicking the box and then the option; Fillhand records the option by its text, so {{row.Country}} works in the click step's text.

Tips that save a rerun

  • If a value isn't found, the run stops on that row and says “option not found: …” — usually a spelling difference in the sheet.
  • Frameworks like React ignore values set the wrong way; Fillhand fires the same events a real user would.
