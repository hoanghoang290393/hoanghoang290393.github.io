Guide

Typing the same client into three portals? Save them once.

Quote requests, registrations, applications: the details are the same, the portals are different, and none of them talk to each other.

What you need: Chrome, the free Fillhand extension and your client details. No account, no code. Your data never leaves your computer.

Step by step

  1. Create an autofill profile for the client (or start from the Company details template).
  2. Open each portal's form and press Alt+Shift+F. Fillhand matches fields by label, name and placeholder, so one profile fits most portals.
  3. For a portal with odd field names, add a rule with a CSS selector for that field only.
  4. Doing many clients? Put them in a CSV and record one macro per portal with {{row.Name}} placeholders.

Tips that save a rerun

  • Mark fields like ID numbers as sensitive: they are never synced or exported.
  • Portals that ask for a CAPTCHA pause the run and notify you.
