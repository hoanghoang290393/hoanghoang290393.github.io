Fillhand for teams

Give a team of 3 to 50 the same macros and autofill profiles, with no server and no new admin console. Everything goes through the Chrome policy you already use.

Roll-out

  1. Buy Team ($45/month or $449/year for 5 users; buy another Team for more). You receive one licence key that works on 5 computers.
  2. Google Admin → Devices → Chrome → Apps & extensions (or GPO / macOS plist): add the Fillhand extension ID as Force install, pinned.
  3. In Policy for extensions paste the JSON below.
  4. On a test machine open chrome://policy → Reload policies and check the Fillhand entry.
{
  "LicenseKey":    { "Value": "FILLHAND-…" },
  "Library":       { "Value": "<contents of a Fillhand backup file>" },
  "DisableSync":   { "Value": true },
  "DisableExport": { "Value": true }
}
  • Library — macros and profiles every user gets, labelled “Organization”, read-only, updated when you change the policy. Users can duplicate one to adapt it.
  • LicenseKey — activates Team on every machine; the licence field is locked.
  • DisableSync / DisableExport — keep data from leaving the machine through Chrome sync, file export or CSV download.

Security summary

  • No servers, no accounts, no analytics. Code runs locally; no remote code (Manifest V3).
  • Only outbound request: licence check to api.polar.sh.
  • Password fields and values marked sensitive are never recorded, synced or exported.
  • Site access is broad because users automate arbitrary internal sites; the content script acts only when a user runs a macro or has an autofill profile for that site.
  • CAPTCHAs are never solved or bypassed.
