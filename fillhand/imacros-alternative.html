Migration guide

iMacros stopped working in Chrome. Bring your macros with you.

Chrome disabled iMacros as part of the Manifest V2 shutdown. If you still have a folder of .iim files that fill forms from a CSV, Fillhand can import them and run them again.

Install Fillhand — free

Import in one minute

  1. Install Fillhand and open its side panel.
  2. On the Macros tab click Import iMacros and pick your .iim file.
  3. Read the short list of notes at the top of the new macro — every line Fillhand could not translate is listed with its line number.
  4. If the macro used SET !DATASOURCE, import the same CSV on the Data tab. iMacros CSVs usually have no header row: choose ⋯ → First row is data.
  5. Set the macro's data source to that file and press Run. {{!COL1}} became {{row.#1}}, so column order stays the same.

What you redo by hand

  • Passwords. iMacros stored them encrypted; Fillhand never imports or records them. Log in yourself before the run, or type into the marked step.
  • XPATH, screen-coordinate clicks, EVAL() JavaScript. Re-pick the element with the picker (two clicks).
  • File uploads and SAVEAS. Browsers do not let extensions choose files for you.

Why people switch to Fillhand

  • Runs on current Chrome (Manifest V3) and Microsoft Edge.
  • No account and no server — same as iMacros, your data stays local.
  • Failed rows are flagged and can be re-run alone; a status column goes into the exported CSV.
  • Free for unlimited runs; spreadsheet runs are $8.99/month — no enterprise licence needed.
My macro used a CSV with a header row.

Then skip “First row is data”. Positional placeholders like {{row.#2}} work with or without a header, and you can rename them to {{row.Email}} later.

Can I convert many .iim files at once?

Import them one by one for now — each import shows its own checklist, which is what keeps conversions honest.

Something did not convert right.

Open an issue at our support page with the .iim file (remove anything private) and we will fix the importer.
