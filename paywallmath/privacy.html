Privacy Policy

Paywall Math · AutoVideo Uploader · Last updated 28 October 2026

Who uses the app

AutoVideo Uploader is a private desktop tool used only by the owner of the Paywall Math YouTube channel to manage that channel. It does not collect data from viewers or other people.

Google / YouTube data the app accesses

With the owner's consent (Google OAuth), the app uses the YouTube Data API and YouTube Analytics API to: upload the channel's own videos, thumbnails and captions; create and update the channel's playlists, channel description and banner; and read the channel's own video statistics to decide what to make next.

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

Storage and sharing

The OAuth token and statistics are stored only on the owner's own computer; statistics are deleted after 30 days. Nothing is sold, shared with third parties, or used for advertising. Google user data is used only for the functions listed above, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time at security.google.com/settings/security/permissions and delete the local files; the app then keeps no Google data.
